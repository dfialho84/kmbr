## Stack

- **Next.js 16.2.6** with App Router — `src/app/`
- **React 19.2.4**
- **TypeScript 5**
- **Tailwind CSS 4** (PostCSS via `@tailwindcss/postcss`)

## Stack

- **Framework**: Next.js 16.2.6 com TypeScript 5 e React 19.2.4
- **UI**: Tailwind CSS 4 + shadcn/ui
- **Validação de Fomulários**: zod
- **Forms**: react hook form
- **Testes unitários/integração**: Jest
- **Testes E2E**: Cypress + Cucumber
- **Testes de carga**: k6
- **Email (dev)**: Mailhog
- **Infra local**: Docker Compose (serviços de ambiente de teste — comente a inclusão de cada serviço ao adicioná-lo)
